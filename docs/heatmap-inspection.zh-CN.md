# 热图检查

热图用于定位压制前后变化较集中的区域。进入热图模式后，浏览器读取当前 Src 与所选 Rip/Flt 原图，在 Web Worker 中分析；旧图组直接使用新算法，无须重新上传或修改数据库。内部站与静态公开站共享同一组件。

## 使用

- 默认“仅热图”便于观察微差；“叠加”可调整透明度，“原图”显示当前对比列。
- 灵敏度提供保守、自动、增强 2×/4×，只改变色阶，RMS 和区域排序保持不变。
- 最多标出六个分散热点，按钮显示区域 RGB RMS。点击后进入同一对比列的 A/B 300% 视图，定位对应原图区域；手机旋转时同步转换坐标。靠近边缘的位置受现有平移边界约束。
- 色阶上限和全图 RMS 均以 0–255 为单位。颜色按当前帧自动展开，不同帧的相同颜色可能代表不同绝对差异，应同时看数值。
- 原图读取失败、尺寸不一致、超时或浏览器计算不可用时显示错误并可重试；仅在预生成热图对应当前对比列时提供回退。

分析结果只留在当前页面内存。切换图片、对比列或离开热图后释放 worker 和结果 URL；调整灵敏度重用已算出的误差，不重复下载原图。分析过程中显示当前对比原图，不沿用上一组热图。

## 算法 regional-rms-v2

旧版以完整 0–255 范围映射差异，再叠加模糊与光晕，接近无损的压制变化容易落在暗色区域。新版使用以下固定步骤：

1. 读取浏览器解码后的原尺寸 RGBA 像素，不先缩小两张图片。
2. 按像素计算三个通道的均方差。透明度以预乘 RGB 处理，并计入 alpha 差异，透明像素中不可见的 RGB 不贡献热点。
3. 对误差能量作 5×5 局部平均，再开方得到局部 RMS。先求误差再汇聚，正负交替的细小误差不会因缩图相互抵消。
4. 显示强度减去 1 级噪声底并截断到零，以全图第 99.5 百分位选择色阶上限，上限至少为 4。稀少极端像素不会压暗整幅画面，接近一致的图也不会无限拉伸。
5. 灵敏度作用于显示强度，随后应用 0.75 次幂映射到暗灰、紫、橙、浅黄。输出 PNG 不加装饰性模糊或光晕。
6. 热点独立使用原始能量：分块尺寸为短边约 1/24，最小 16 像素；区域 RMS 必须大于 `max(1.5, 全图 RMS × 1.25)`。按分数选出最多六个区域，抑制相邻重复热点。均匀变化可以有明显颜色，但不强行产生集中热点。

上传时也通过同一共享算法生成备用 PNG，新生成素材的 note 记录算法版本并保留比较源路径。历史预生成文件保持原样，显式回退时不提供新算法的统计或灵敏度。

## 判断边界

这是变化定位工具。抗锯齿、去噪、色彩处理、锐化和压制失真都会贡献差异，颜色不能直接判断画质变好或变坏。热点以局部平均误差排序，单个强像素仍可能入选，需要回到原图确认。

输入须对齐且尺寸一致；不会自动配准或拉伸。分析使用浏览器解码的 8-bit sRGB 画布像素，无法代表视频原始 10/12-bit、HDR 或未经浏览器色彩转换的数据。素材服务器需要允许 CORS 读取。单张超过 1200 万像素会提示使用预生成图或裁切分析，首次读取与计算限时 30 秒；这项限制用于控制手机内存占用。

开发校准使用用户指定图组的第一帧（暗色云层渐变与文字）和第三帧（动画画面）。两对 1920×1080 原图的全图 RGB RMS 分别约为 1.34 与 1.59；新版自动色阶能显示文字、云层和动画轮廓上的细微变化。真实素材仅用于本地校准，不作为仓库或 CI 测试资源。
